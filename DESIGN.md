# Discord panels

Direction comes from the owner's requested compact summaries, restrained footers,
consistent usage meters, quiet refresh indicator and direct Home navigation.
ENERGY 1 / RHYTHM 2 / MOTION 1. Motion is limited to a real in-flight refresh or action.

- Discord's native embeds and controls preserve its light/dark themes, font scaling,
  mobile reflow, focus treatment and keyboard controls.
- A single overview headline shows the health decision first; detail screens use
  fields shaped by their data rather than repeating the overview.
- The embed accent communicates normal, healthy, warning or failure state.
- Ten-segment usage meters compare CPU, memory and storage consistently.
- Text labels carry meaning without decorative emoji, custom fonts or images.
- The footer contains one useful command hint and Discord's timestamp.
- Lists are paginated before Discord's field or selection limits are reached.
- Deeper panels include their parent and Home to avoid repeated backtracking.
- Home exposes each available section as a native button for direct access,
  matching the owner's preferred navigation; only long item lists use selectors.
- A refresh retains the complete previous sample and changes its footer only.

Discord owns visual rendering, contrast, touch target sizes and theme behaviour.
Offline verification checks payload limits, states and control callbacks; it does
not claim pixel or keyboard testing inside a real Discord client.
